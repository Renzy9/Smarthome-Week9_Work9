# WEEK9_WORK9 changes

Added a MySQL schema, a safe initial seed, a standalone SQL import, and a small Node.js backend matching the frontend's six existing API routes. Database credentials are configured in the private server environment. The existing frontend source, simple UI, logo, preferences, and route contract are unchanged.

Device changes now persist in MySQL when the frontend is connected to this backend. Sensor readings come from the latest stored database row. The seeded data remains a classroom demonstration rather than physical hardware control.

See README.md for MySQL setup and the two-terminal startup instructions. MySQL runtime binaries, installed dependencies, local credentials, and temporary test databases are not included in the ZIP.
